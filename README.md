## Learning Path

A practical progression through this collection is:

1. Start with **BuffemR Discovery** and **OpenEMR Version Trail** to practice application and service discovery.
2. Continue with **BuffemR Enum Breakout** and **Gobuster Paths: Find the Hidden App** for structured web enumeration.
3. Study **OpenEMR Auth Break-In**, **Cred Hunt EMR Leak**, and **BuffemR Credential Crackdown** for authentication and credential-focused challenges.
4. Explore **Hidden Files Hidden Shells** to develop filesystem and shell investigation skills.
5. Practice **Shellsnap: Stabilize the Pwn** for shell stabilization concepts.
6. Study **Shellshock to Root 3** and **Auth RCE Breakout** for vulnerability and remote-code-execution concepts.
7. Finish with **BuffemR Breakout Lab** as a broader CTF-style exercise.

## How to Use the Labs

- Read each lab's instructions before beginning.
- Use these exercises only in their authorized CTF or training environments.
- Record discovered paths, application versions, credentials-related clues, and security observations.
- For Gobuster and enumeration exercises, understand the purpose of the discovery process.
- For authentication challenges, document the security concept being demonstrated rather than reusing credentials elsewhere.
- For Shellshock and RCE exercises, work only against the provided lab target.
- Keep a personal lab notebook with commands, findings, mistakes, and lessons learned.
- Never apply these techniques to systems without explicit authorization.
